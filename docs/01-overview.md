# 01 项目概述

## 背景

[ripienaar/free-for-dev](https://github.com/ripienaar/free-for-dev) 是 GitHub 上最大的"开发者免费服务清单"（约 139,600 Star、14,800 Fork），收录 SaaS/PaaS/IaaS 等提供免费额度的服务。其数据全部存放在一份 README.md 中，官网 free-for.dev 只是用 docsify 渲染这份文件，无后端、无结构化数据。

上游数据现状（2026-10-15 实测）：

| 指标 | 数值 |
|---|---|
| 分类数 | 57 |
| 条目数 | 1,339 条链接条目（1,274 顶级 + 65 带链接子条目），另有 33 条纯文字备注、6 条无描述条目；README 顶部目录的 57 行与条目格式同构，解析时必须跳过 |
| 描述文字量 | 约 19.5 万字符（条目描述约 19.1 万 + 备注与非常规描述约 0.4 万，2026-10-15 实测） |
| 更新频率 | 最近 29 天约 100 次 README 提交，平均每天 3–4 处变动 |
| 许可 | 无 license 文件（默认保留版权，需合规处理，见 05） |

## 机会

- 官方只有英文站，无中文版本。
- 现有中文衍生项目均不是"上游翻译 + 自动同步"模式：
  - tvvocold/free-for-dev-zh（1,703 Star）是独立的"国内服务清单"，2024-04 后停更；
  - zhezzma/free-for-dev-cn（99 Star）无影响力。
- 结论：**完整翻译上游 + 每日自动同步 + 中文站点体验**这个形态是空白的，本项目的核心价值就在这三点组合上。

## 产品定位

一个面向中文开发者的免费服务目录站：内容与上游天级一致，界面为中文优先的双语展示，视觉品质达到"成品级"而非"脚本输出"。

## 目标

- G1：全量翻译上游约 1,340 个条目，数字与配额信息保真。
- G2：每日定时自动完成"拉取 → 比对 → 增量翻译 → 发布"，无需人工干预。
- G3：站点具备搜索、分类浏览、双语对照、深色模式，视觉精致、移动端可用。
- G4：总持有成本约等于零（托管与 Actions 免费，翻译走智谱 GLM 免费模型；极端限流时才有按量付费兜底，见 05 风险登记）。

## 非目标（v1 明确不做）

- 用户投稿、登录、评论等社区功能。
- 收录自托管开源软件（与上游定位一致，只收 as-a-Service）。
- 国内可访问性检测/标注（访问性变化快，标注即过期，留给 v2 评估）。
- 独立 App、RSS（RSS 可作 v2 低成本加分项）。
