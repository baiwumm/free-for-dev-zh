# 05 里程碑与风险

## 里程碑（单人，约 7–8 天，含 1–2 天缓冲）

| 里程碑 | 工期 | 产出 | 验收标准 |
|---|---|---|---|
| M1 数据流水线 | 1–1.5 天 | `scripts/` 同步四件套（fetch/parse/guard/diff）+ `data/entries.json` 基线 | 产出约 1,340 条英文数据，guard 通过，02 章验收标准全过 |
| M2 翻译上线 | 1–1.5 天 | `translate.mjs` + 全量首翻 + `categories.json` 人工分类名 | 数字校验 100% 通过，人工抽检 30 条质量可接受 |
| M3 站点骨架 | 1 天 | Next.js 16 + Tailwind v4 + Fumadocs 初始化、内容直读 `entries.json`、首页/分类页/详情页可跑 | `pnpm dev` 下三类页面渲染真实数据 |
| M4 视觉定制 | 1–2 天 | 字体、配色、条目列表、favicon 降级、深色模式、响应式 | 03 章视觉验收标准全过 |

## 合规说明

1. 上游 `ripienaar/free-for-dev` **没有 license 文件**，默认保留版权。服务名称与网址属于事实性数据，主要风险在于人工撰写的描述文字；翻译属于衍生表达。
2. 缓解三件套：
   - **署名**：全站页脚固定标注"数据整理自 ripienaar/free-for-dev"并链接；每条译文可链回上游锚点；
   - **双语**：英文原文与译文并列展示，译文标注"机器翻译，仅供参考，以原文为准"；
   - **沟通**：上线稳定一周内给维护者 R.I. Pienaar 发邮件说明用途（翻译 + 每日同步 + 署名回链），回复以备忘记录入 `docs/`。
   - **落点**：署名与免责声明文案沉淀为仓库根目录 `NOTICE.md`（见 04 仓库结构）。
3. 本仓库 LICENSE 为 MIT，覆盖的是**本项目自有的代码与译文组织**，不构成对上游数据的许可声明，两者不要混淆。
