# 03 站点需求

## 页面结构

| 路由 | 页面 | 内容 |
|---|---|---|
| `/` | 首页（索引式） | 报头（定位语 + 搜索 + 浏览入口）+ 近 7 天更新速览（新增 / 更新计数 + 条目链接）+ 全部分类索引（序号 / 中英名 / 条目数，桌面双栏）+ 统计行（条目总数 / 分类数 / **最近同步时间**） |
| `/docs` | 概览 | 与首页同源的分类索引 + 收录与翻译统计（已翻译 X/Y 条） |
| `/docs/[category]` | 分类页 | 该分类下全部条目，细线分隔的行列表，页内可筛选 |
| `/entry/[id]` | 条目详情页 | 服务名、官网链接、双语描述（中文优先、英文可展开）、分类面包屑、回链上游原文 |
| `/about` | 关于页 | 数据来源、同步机制说明、翻译免责声明、上游链接 |
| `/feed.xml` | RSS 订阅源 | RSS 2.0：最近更新的 50 条条目（按条目更新时间降序），页脚入口 + 全站 `<head>` 自动发现 |

文档区（`/docs` 下）侧边栏为「概览 + 57 个分类」，不含首页/关于等额外导航链接；顶栏站点标题链回首页。

## 功能需求

- **FR-1 双语展示**：所有条目中文描述为主，英文原文可展开对照。语言本身不做切换（UI 固定中文，内容双语）。
- **FR-2 搜索**：单套体系。⌘K 命令面板（cmdk + Fuse.js，客户端模糊匹配全量条目（自建索引由 entries.json 生成、字段裁剪控制体积）），首页与文档区均可唤起；快捷键按平台显示（macOS「⌘K」/ 其他「Ctrl+K」），输入时高亮名称与描述中的匹配片段；分类页「页内筛选」为纯客户端过滤，不另建索引。Fumadocs 内置静态搜索不启用（静态导出下索引需全量下载，见 04 说明）。
- **FR-3 深色模式**：next-themes，默认跟随系统，可手动切换，无闪白（SSR 注入 script）。
- **FR-4 数据新鲜度可见**：首页索引区标注「同步于 <日期>」，页脚标注上游 commit sha——这类站点用户最大的不信任是"数据是不是死的"。
- **FR-5 外链安全**：所有外部链接 `rel="noopener noreferrer"`，新标签打开。
- **FR-6 条目降级**：翻译失败/被跳过的条目展示英文原文并标注「未翻译」，不留空白。
- **FR-7 分享与订阅**：站点级 OG / Twitter 分享卡片（`app/opengraph-image.png` 1200×630 静态图 + 根布局元数据，各页 `og:title` / `og:description` 取本页元信息）；RSS 订阅：静态 `/feed.xml`（RSS 2.0，最近更新的 50 条），页脚入口 + 全站 `<head>` 自动发现 link。
- **FR-8 更新可见**：首页索引区显示近 7 天新增 / 更新计数（以 `synced_at` 为基准）与最多 3 条条目链接（按更新时间降序）；窗口内无变化时整行不渲染。

## 视觉要求（核心验收项）

设计语言「**开放索引 / Open Index**」（2026-10-16 改版定案，替换首版 emerald 方案）：像一本印刷考究的参考手册目录——纸墨单色为底，唯一的钴蓝（stamp blue）强调色只用于交互与引用标记；层级靠字号、留白与细线表达。

- **字体**：全站 **Maple Mono CN** 自托管（SIL OFL 1.1）——站点子集 `public/fonts/maple-mono-cn-regular.woff2` 按实际用字生成（≈280KB，`pnpm fonts` 重新生成）；`unicode-range` 之外的字符回退系统栈；`--font-sans` 与 `--font-mono` 首位均为该字体；不做字体切换、不引外链字体。
- **配色**：纸墨（paper & ink）深浅两套，色值以 oklch 定义于 `src/app/globals.css` 并同步覆盖 fumadocs `--color-fd-*`；强调色仅钴蓝一色（浅色 ≈ `#1d4aa3`，深色 ≈ `#90b0ea`）。不使用渐变光斑、彩色底块、阴影堆叠与纯黑纯白大色块。
- **索引排版**：分类索引 = 序号 + 中文名 + 引导点线 + 条目数 + 英文名，桌面双栏流式排布；条目列表为细线分隔的行（无卡片），favicon / letter avatar + 名称 + 一句话描述 + 可选「未翻译」标。
- **图标兜底**：Google favicon 服务国内不可达，用「域名首字母 + 名称哈希取色（纸墨色板）」的 letter avatar 兜底，真实图标 `onerror` 自动降级，国内外访问均不破版。
- **微交互**：颜色 / 透明度过渡（hover 强调色、行底色），不做位移动画；`prefers-reduced-motion` 时关闭平滑滚动。
- **响应式**：移动优先，375px 起步无横向滚动；搜索面板移动端全屏化。

## 非功能需求

- **NFR-1 性能**：首屏 LCP < 2.5s（4G 模拟）；字体子集 ≈0.3MB 走 `font-display: swap`，不阻塞首屏；`_next/static` 与 `/fonts/*` 强缓存（见 04）；搜索索引懒加载一次、gzip ≈110KB（随条目数缓增），分类页页内筛选零请求。
- **NFR-2 SEO**：全部页面静态生成；`sitemap.xml`（含 `lastModified`）；分类页与详情页独立元信息；站点级 OG 卡片与 RSS（FR-7）为静态产物，不做逐页动态 OG 服务。
- **NFR-3 可访问性**：语义化标签、键盘可达、全局 `focus-visible` 焦点环、对比度 WCAG AA。
- **NFR-4 构建时间**：全量静态生成（1,400+ 页）控制在 5 分钟内（纯静态约束不变，超时先排查构建缓存与并发）。

## 验收标准

- [ ] 移动端 375px 与桌面 1440px 下首页、分类页、详情页无布局破损（改版后待本地预览复核）。
- [ ] ⌘K 搜索输入"数据库"能召回相关条目且响应 < 100ms。
- [ ] 断网 favicon 的场景下图标降级为 letter avatar，无破图。
- [ ] 字体子集外的生僻字场景回退系统字体、无空白字块。
- [ ] Lighthouse 性能与可访问性均 ≥ 90。
- [ ] 深浅色模式下均无纯黑纯白大色块，文字对比度达标。
- [ ] 分享链接在支持 OG 的平台展示站点卡片（标题 + 描述 + 图片）。
- [ ] `/feed.xml` 通过 XML 解析校验，条目含 `title` / `link` / `guid` / `pubDate`。
